你的时间，正在被「杂活」吃掉

  • 整理 issue、写周报、巡检服务、批量改文件——每周都在重复手动做，或写一堆零散的 shell 脚本，散在各自机器上

工蚁就是为这四件事造的一支私有打工队——它住在你的机器上，听得懂你的话，认得你的手机。

不是又一个 AI 助手，是你的 AI 打工队

① 本机私有 —— 执行在你机器上

引擎跑在你自己的机器上，文件读写、命令执行、git 提交全在本机发生。

代码与数据不经过我们的服务器；模型端点由你选——用本地模型或自建网关，内容完全不出机。你的私有，是结构性的，不是承诺的。

② 手机 IM 指挥 —— 发条微信就能派活

微信 / 钉钉 / 飞书 / 企业微信 / QQ——用你本来就在用的 IM。

发消息 = 派活 / 查进度 / 审批确认 / 收成果。出差、通勤、饭桌上都能盯。Team 档还能在私聊里审批设备、回答跨机提问——高危操作永不进手机。

③ 成果与经验都是一等公民 —— 看得见，也留得住

产出是登记在册的可交付资产（文件、报告、草稿），不是一段会滚走的聊天。

事件溯源引擎记录每一步动作，可暂停、可恢复、可重放、可审计。

同一个项目第二次开工不用从头讲（项目画像自动成型）；同类活的经验沉淀到岗位上，够格的晋升成规范 / 技能 / 知识，也能撤回。这是确定性蒸馏，零训练。

④ 机器们开始互相认识 —— 你不用再决定「哪台来干」

它看看家里哪台机器最会干这件事、此刻最闲，把活派过去；干完了，结果自己回来。

任务所需能力、节点匹配分、派单理由都写在协同看板上；父任务失败会自动收口仍在跑的子任务。协同属团队版旗舰能力，试用期内同样可用。

常见问题

我的代码会被上传吗？

引擎在你本机执行，文件、命令、git 都不经过我们的服务器。需要说准确的是模型调用：请求直达你自己配置的端点——用云端模型时，上下文会发给那家模型厂商；用本地模型或自建网关，内容才完全不出机。你填的模型 Key 只在你本机使用，当前版本没有遥测。

支持哪些模型？

任何 OpenAI 兼容端点，或你自己的网关。BYO Key，你说了算。

一定要用微信吗？

不。微信 / 钉钉 / 飞书 / 企业微信 / QQ 任选；也可以只在桌面端用，不接 IM。

在手机上审批设备安全吗？

设备授权与跨机问答仅 Team 档开放，且只在私聊里处理；高危操作永不进入 IM 授权台。每条审批与回答都落库并留审计记录。

「岗位」是什么？会不会替代人做管理？

岗位是知识载体 + 派活标签：同一类活干过之后，可迁移的教训沉淀到这个岗位上；任务可以按岗位派活。经验要你确认才晋升成规范 / 技能 / 知识，也能随时撤回。它不做组织管理，也不替你决定人事——不是「自动学会」，是确定性蒸馏、零训练。

项目知识和岗位经验会上传到你们服务器吗？

不会。项目画像、知识卡、岗位经验都落在你本机的库里；岗位经验不跨机、不回传。团队共享库只有在你主动分享后团队内才可见，已删除的内容不会再出现在候选里。

能操作网页吗（点按钮、填表单）？

目前不内置浏览器自动化。当前定位是文件 / 命令 / API 类任务；浏览器能力在路线图上。

开源到什么程度？

引擎核心与桌面端开源（AGPL-3.0），本页所列的档位能力都在桌面端可核对；云端协作服务尚未发布，发布时另行说明。开源范围与许可见仓库的 LICENSE 与 COMMERCIAL_LICENSE。

现在能买吗？买完就能装吗？

Pro 月付 / 年付、早鸟终身与 Team 授权包已在 面包多店铺 开售；企业版暂不售卖。安装包已发布——macOS 版（Apple Silicon）已完成 Developer ID 签名与 Apple 公证；Windows 10/11 与 Linux x86_64 版未做代码签名，首次运行可能被系统提示。均可从 GitHub Releases 下载。Intel Mac 版本暂未提供。桌面端自带 14 天团队版试用，可以先试再买。

正是为你们做的。它省的是「重复杂活」的时间——那正是拿来做产品的时间。
