不是又一个 AI 助手，是你的 AI 打工队

① 本机私有 —— 你的代码不出门

引擎跑在你自己的机器上，文件读写、命令执行、git 提交全在本机发生。

代码与数据不经过我们的任何服务器。你的私有，是结构性的，不是承诺的。

② 手机 IM 指挥 —— 发条微信就能派活

微信 / 钉钉 / 飞书 / 企业微信 / QQ——用你本来就在用的 IM。

发消息 = 派活 / 查进度 / 审批确认 / 收成果。出差、通勤、饭桌上都能盯。

③ 成果一等公民 —— 干了什么，看得见

产出是登记在册的可交付资产（文件、报告、草稿），不是一段会滚走的聊天。

事件溯源引擎记录每一步动作，可暂停、可恢复、可重放、可审计。

常见问题

我的代码会被上传吗？

不会。引擎在你本机执行，文件、命令、git 都不经过我们的服务器。你填的模型 Key 也只在你本机使用。

支持哪些模型？

任何 OpenAI 兼容端点，或你自己的网关。BYO Key，你说了算。

一定要用微信吗？

不。微信 / 钉钉 / 飞书 / 企业微信 / QQ 任选；也可以只在桌面端用，不接 IM。

能操作网页吗（点按钮、填表单）？

目前不内置浏览器自动化。当前定位是文件 / 命令 / API 类任务；浏览器能力在路线图上。

开源到什么程度？

引擎核心与桌面端开源（AGPL-3.0），本页所列的档位能力都在桌面端可核对；云端协作服务尚未发布，发布时另行说明。详见仓库的 OPEN_SOURCE_SCOPE。

现在能买吗？买完就能装吗？

Pro 月付 / 年付、早鸟终身与 Team 授权包已在 面包多店铺 开售；企业版暂不售卖。安装包已发布——macOS 版（Apple Silicon）已完成 Developer ID 签名与 Apple 公证，可从 GitHub Releases 下载 dmg / zip。当前仅支持 macOS 13+ 的 Apple Silicon，Intel Mac 与 Windows 暂未提供。 桌面端自带 14 天 Pro 试用，可以先试再买。

一个人 / 小团队值得用吗？

正是为你们做的。它省的是「重复杂活」的时间——那正是拿来做产品的时间。
